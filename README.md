# Hippo · California Carrier Opportunity

A static site (no build step) with five tabs: Executive summary, Customer opportunity, Marketing Analysis, Carrier economics, Appendix. All charts are inline SVG, so the site needs no external scripts.

- **View locally:** open `index.html`, or run `python3 -m http.server` in this folder.
- **Publish:** push to a private GitHub repo, then Settings → Pages → Deploy from branch → `main` / root. Each tab can be linked directly, e.g. `/#growth`.

Contains internal book data. Keep this repository PRIVATE: it contains internal book, loss and customer data.


All files live at the repository root (no folders), so a plain drag-and-drop upload of every file works.
